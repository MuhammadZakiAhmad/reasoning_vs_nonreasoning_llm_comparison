**Lessons learned**: Colab exports carry silent failure modes — a broken call inside a broad `try/except` hid a NameError that would otherwise fail fast, so the reasoning half of this script had never actually loaded. Prefer narrow exception handling around model loading. Separately: the import target and the execution target are different machines, so the file must stay runnable under Colab's `%run` — valid plain Python (no `!pip` escapes) with `display()` for anything that must be visible — and be invoked with `%run`, never `!python`.

Three more, all from reading the chickens/cows output instead of trusting the printed verdicts: (1) **a verdict is not evidence** — `CORRECT` came from markers that only ever appeared inside the reasoning trace, and the fix was to grade a *scope*, not a string; (2) **hitting a token cap is not the same as being truncated** — the IFT answer completed and then looped, and the old warning asserted the wrong cause; (3) **a degenerate generation silently poisons an average** — `average_prompt_attention()` over a loop measures the loop, so collapse must be detected and excluded before aggregating, not averaged through.
