**Lessons learned**:
- **A detector that reports "clean" is worse than no detector.** Repeated twice this session, in both directions: the S1 n-gram scan manufactured confidence, and S2's tail-only trim reported a 441-token "clean" average that was 90% chat drift.
- **Check the expectation before the code when a test fails.** Four separate test failures this session were wrong assertions (fraction-of-total vs fraction-of-kept, a vacuous boundary test, `None` passed as a truthiness condition, wrong `{:6d}` padding) — the shipped code was correct every time.
- **A test that passes vacuously is worse than no test.** The sink-column bug survived because the test's reader head had a hard-zero sink column. Fix: include a partially-sunk-but-kept head.

- **When numbers move, ask which knob moved.** Two sessions of elaborate analysis sat on top of a single missing keyword argument (`eos_token_id`). The diagnostic that found it was three lines printing decoded tokens around a cut.
