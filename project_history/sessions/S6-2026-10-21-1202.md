**Lessons learned**:
- **A raised cap is a test, not a conclusion.** The 1024 result said "does not terminate" and the 2048 result said "terminates on 3 of 7" — same code, same models, and the difference was entirely the horizon. Any number about a cap has to travel with the cap.
- **A bounded claim has to be phrased as bounded.** "Did not terminate within 2048 tokens" is supportable; "does not terminate" is not, and the difference is exactly where a paper goes wrong.
- **My own code has the bug class too.** The layer bootstrap was handed the answering table twice, which would have reported C1 = 0 for every prompt — the same class as the S1/S2 eos bug, in miniature: one quantity silently standing in for another. `pyflakes` flagging an unused local was the clue.
- **A metric that silently skips is worse than one that fails loudly.** The reader-head comparison returned `None` and printed nothing when a model had no surviving head, which would have hidden the most interesting fact it could report.
- **A significance test is only as honest as the comparison it is computed on.** The bootstrap was paired and rigorous, and still reported `P(C1 > C2) = 0.013` on a comparison between a 1028-token window and a 436-token window. The rigour was in the resampling; the flaw was in what was being resampled. Length-matching and re-slicing are not optional extras — they are the measurement.
- **Two different populations make a distance, not a comparison.** Dropping sink-dominant heads from each model separately left the two sides holding different head sets, and part of the "model gap" was which heads survived. The tell was a threshold at which the number collapsed exactly where the populations diverged most. When two sides are filtered, they must be filtered by the SAME rule.
- **A "significance" number is not a conclusion, and a counter-intuitive one gets read hardest.** The one row where the model gap clearly won was the row with the biggest effect and the best controls — which is exactly the row a reader would quote. It turned out to be the artifact.
- **The checks that pass are not the checks that find things.** `py_compile` and `pyflakes` were both clean on a script that crashed on the first real numpy array. The local dry run against synthetic data is what caught it.
